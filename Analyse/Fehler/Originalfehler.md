# Fehler im Original (BLADEM.EXE 3.02, „Die Schicksalsklinge“)

**Stand 20.10.2026** – 417 Einträge (310 eigene + 107 aus dem Netz, Nr. 311–417). Davon 381 echte Fehler (**kritisch 25**, **mittel 147**, **egal 209**) und 36 geprüfte Markierungen bzw. Meldungen, die sich als kein Fehler erwiesen haben. Quelle: 132 neu, 161 Bright-Eyes, 17 beide, 107 Netz. 47 Einträge sind ausnutzbar (Exploit). Von unseren 310 Einträgen waren 109 im Netz bekannt, 201 nur bei uns. Von den 132 eigenen Neufunden kannte das Netz 20, 112 kannte vorher niemand. Spalte `netz` in `Fehler_Raster.tsv`, Einzelabgleich in `Fehler_bekannt_im_Netz.tsv` und `Fehler_aus_dem_Netz_geprueft.tsv`.

Alle Fehler sind im rekonstruierten Quelltext **bewusst so nachgebaut**, damit der Build bytegleich mit dem Original bleibt. Behoben wird später per Schalter (`M302de_ORIGINAL_BUGFIX` bzw. ein eigener Schalter je Fehlergruppe), der Standard bleibt bytegleich. Die Fix-Vorschläge unten sind nur Text.

Grundlage: alle `Original-Bug`-Vermerke und alle `M302de_ORIGINAL_BUGFIX`-Blöcke in `src/*.c`, `*.cpp`, `*.h`, die Zeilen `originalfehler_neu`/`originalfehler_be` der Wellen G1–G7 und `kandidaten.tsv`. Gleiche Stellen und gleiche Mechanismen an mehreren Stellen sind zu einem Eintrag zusammengefasst (Orte in der zweiten Spalte). Jeder Eintrag wurde an der Stelle im Code nachgesehen. Die Einordnung steht in `Fehler_Raster.tsv`, die Übersicht in `Fehler_Raster.md`. Bright-Eyes-Nummern stehen in der Spalte Quelle.

Schwere: **kritisch** = Absturz, Hänger, Spielstand kaputt, Quest blockiert oder großer Exploit; **mittel** = spürbar falsche Regeln, Werte, Preise; **egal** = kosmetisch, toter Code, folgenlos; „(unsicher)“ = kann Absicht sein oder hängt von ungeprüften Daten ab.
