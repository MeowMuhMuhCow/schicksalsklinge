# Realms of Arkania: The Northland Trilogy — Unified Launcher (`NORDLANDTRILOGIE.EXE`)
## Native Release Package (*Die Schicksalsklinge* V3.02de & *Sternenschweif* V1.02de, without DOSBox)

Unified launcher and native Windows ports for **Das Schwarze Auge / Realms of Arkania: The Northland Trilogy** (German original releases by Attic Entertainment Software):
- **Part 1:** *Die Schicksalsklinge* (1992/1993) — **included** (`SCHICK_PORT.EXE`, `SCHICK_PORT_WICHTIG.EXE`, `SCHICK_PORT_ORIG.EXE`)
- **Part 2:** *Sternenschweif* (1994) — **included** (`SCHWEIF_PORT.EXE`, `SCHWEIF_PORT_WICHTIG.EXE`, `SCHWEIF_PORT_ORIG.EXE`)
- **Part 3:** *Schatten über Riva* (1996) — prepared (shows `Coming soon` while no Riva port executable is present; displays the authentic Riva title artwork as soon as the Riva game folder is configured)

---

## 1. Quick Start

1. Double-click **`NORDLANDTRILOGIE.EXE`**.
2. **Provide Original Game Data:**
   - Standard GOG installations for all three games are detected automatically (`✔ Game data found`).
   - Or simply **drag & drop** your game folder or an archive (`.zip` / `.7z` / `.rar`) containing the original game files directly into the launcher window.
3. **Configure & Start Directly on Each Card:**
   - Press **`F2`** or click **`DE (F2)` / `EN (F2)`** in the top-right corner at any time to switch between German and English.
   - Each card displays the **authentic 4:3 title image read directly at runtime from your game folder** (or a clean emblem placeholder if no folder is configured yet).
   - Click **`>> Start Game`** (or **`Settings...`** for detailed options).

## 2. Highlights (Stage 4)

- **Runtime 4:3 Title Artwork (0 Shipped Image Bytes):**
  - Reads the original title images directly from your configured game folders at startup (`INTRODAT.VOL` / `SCHICK.DAT`, `DATA\STAR.DAT` / `gamea.gog`, `DATA\RIVA.ALF` / `game.gog`), converts the 6-bit VGA palette, and renders them in exact **4:3 aspect ratio** via Nearest-Neighbor with a smooth card gradient. Zero proprietary image bytes are shipped or cached to disk.
- **Clear Player-Friendly Interface (DE & EN via `F2`):**
  - Status badges show **`✔ Program found`** and **`✔ Game data found`** (hovering the mouse over *Program found* reveals a tooltip with the active executable name; **`F1`** opens the help overlay).
- **Authentic 4:3 Display & Scaling:**
  - **Window Size (`[F]`):** **`2x (640×480)`**, **`3x (960×720)`**, **`4x (1280×960)`**, **`5x (1600×1200)`**, or **`Fullscreen`** (`Alt+Enter` toggles fullscreen in-game).
  - **Scaling (`[K]`):** **`Integer (exact multiples)`** or **`Fill (sharp)`**.
- **Three Patch Levels (`[S]`):** **`All Fixes`** (recommended), **`Essential Fixes`**, or **`Original`**.
- **Roll Log (`[P]`):** **`Disabled`** or **`Enabled (with live window)`**.
- **Intro (`[I]`):** **`Play (Original Intro)`** or **`Skip`**.
